# X Ops Skill

一份给 AI 助手（Claude / OpenClaw 等）用的 **X（Twitter）账号运营说明书**。

装上之后，你每天早上说一句「跑今日日报」，它就会：

> 扫今天的热点 → 挑出该去评论的帖子 → 写好评论草稿和发帖草稿 → 打包成一张单子给你审批

你只需要回「1A、2B、发 A」，剩下的它去执行。

⚠️ 这不是一个能独立运行的程序，是一份 **prompt / skill 文档**。全流程需要 AI 有浏览器控制能力（要去读 X 页面上的实时数据）。

---

## 它解决什么问题

大部分人做 X 增长卡在三件事上：

1. **不知道今天该说什么** —— 热点看不过来，看到了也不知道值不值得蹭
2. **评论全是废话** —— "Great post!" 换不来任何人点进你主页
3. **发帖没节奏** —— 灵感来了一天发三条，然后消失五天

这个 skill 把这三件事变成有标准、可重复的流程：每个热点按四个维度打分再决定动作，每条评论必须过「截图测试」，每周内容有固定节奏。

---

## 四个模块

### Module 0 — Profile（账号画像）
**换账号时跑一次，其他模块都依赖它。**

去扒你的 X 主页：bio、粉丝数、最近 20 条原创帖，然后得出：

- **所处阶段**：Tier 1（0-500）/ Tier 2（500-2000）/ Tier 3（2000+），不同阶段打法完全不同
- **声音指纹**：你习惯的句长、语气、emoji 用法、标志性表达 —— 后面所有草稿都按这个写，不是套通用模板
- **内容支柱 + 独家资产**：你凭什么能说这个话题
- **互动网络（三层名单）** —— 这是整套系统的骨架：

| 层级 | 对象 | 数量 | 怎么用 |
|------|------|------|--------|
| 层 1 | 标杆大号（50K+ 粉） | 3-5 个 | 开帖子通知，抢发帖后 10 分钟内评论。不求 follow back，求曝光 |
| 层 2 | 同体量账号（粉丝 ±50%，同 niche） | 10-15 个 | 互相 follow、互相评论，形成互相扩散的增长圈。**这层是核心** |
| 层 3 | 潜力新人（粉丝 < 你的 50%，内容好） | 5-10 个 | 主动 follow 并评论，建早期关系 |

每天按这个名单顺序花 15-20 分钟。Module 1 扫 niche 热点时，也是**只扫层 1 + 层 2 名单里的账号**。

### Module 1 — Daily Monitor（每日热点监控）
三层扫描，输出一份「今日行动包」：

- **Layer A**：搜外部行业新闻（按你的内容支柱生成搜索词，只看 24h 内）
- **Layer B**：X 平台热点 **+ 你三层名单里那些人的帖子**（找正在发酵的 niche 讨论）
- **Layer C**：你自己最近 10 条帖的数据 —— 哪种内容互动是均值 1.5 倍以上（今天强化），哪种低于均值一半（今天别发）

然后每个热点按 **支柱匹配 / 视角独特 / 时效 / 可信度** 四维打分，走决策树给出动作：立刻 QT、只评论、发借势帖、还是直接跳过。

> **关键判断**：0-2000 粉的账号**别追全平台大热点**，优先蹭 niche 小热点。大热点几万条帖子在抢、受众还不精准、窗口只有 2-4 小时；niche 小热点竞争只有几十条、受众全是目标用户、能热 1-3 天。

### Module 2 — Comment（评论引流）
**0-500 粉阶段最重要的模块。** 评论是你在别人的流量里建立声誉的唯一方式。

选帖公式（Tier 1）：

```
✅ 作者粉丝 10K-100K      ✅ 帖子 views 5K-50K
✅ 现有评论 < 20 条        ✅ 发布 < 90 分钟
✅ 话题落在你的内容支柱内   ✅ 有明确论点（不是情绪帖）

❌ 评论 > 50 条 / 发布 > 4 小时 / views < 1K / 政治争议
```

给了五种评论类型（增量价值、视角补充、善意反驳、问题延伸、真实挣扎）+ 一串禁用词。

质量标准里最狠的一条是 **截图测试**：把这条评论截图单独发出去、没有上下文，陌生人看完会觉得有价值吗？不会 → 重写。

### Module 3 — Post（发帖）
按阶段给不同策略：Tier 1 一天 1 条、宁缺毋滥（一条烂帖的伤害大于不发）；Tier 2 一天 2 条 + 每周内容日历。

内置了 X 开源算法的真实权重：

```
Retweet 20x | Reply 13.5x | Profile click 12x | Link click 11x | Bookmark 10x | Like 1x
```

所以整个模块一直在强调两件事：写**值得收藏**的内容（bookmark 权重是 like 的 10 倍），以及故意留一个**回复入口**。另外带外链会被降权 —— 链接放回复里，别放主帖。

还包括发完之后怎么管：前 30 分钟必须在线回评论、1-2 小时后自己在下面补一条、帖子起势了立刻发续集。

## 怎么装

### Claude Code / Claude Desktop

```bash
git clone https://github.com/piupiuyao/X-ops-skill.git
mv X-ops-skill ~/.claude/skills/x-ops
mv ~/.claude/skills/x-ops/x.md ~/.claude/skills/x-ops/SKILL.md
```

⚠️ **必须把 `x.md` 改名成 `SKILL.md`**，否则不会被识别。

### OpenClaw / 其他 agent

把 `x.md` 的内容整个贴进你的 system prompt 或 skill 目录即可，四个参考文档按需一起带上。

## 怎么用

**第一次：**

```
"分析一下 @你的handle"     → 跑 Module 0，生成账号画像（会存进 memory）
```

**之后每天：**

| 你说 | 它做什么 |
|------|----------|
| `跑今日日报` / `早报` / `daily` | 全流程：热点扫描 → 评论候选 → 发帖草稿，打包成一份审批单 |
| `找评论机会` | 只跑 Module 2，给 5-10 个候选帖 + 每帖两版草稿 |
| `帮我写推` | 只跑 Module 3，出 A/B 两版并推荐一版 |
| `看热点` / `今天有什么热点` | 只跑 Module 1 的 Layer A + B |
| `刷新画像` | 重跑 Module 0（换了方向或粉丝量跨阶段时用） |

审批格式：评论回 `1A` / `2B`，发帖回 `A` / `B`，想改就回 `改1` + 你的反馈，不要就 `skip 3`。
